🎯 Tier List Maker – JitJuv
Tier List Maker – JitJuv is a simple and interactive web application that allows users to create, customize, and organize tier lists by ranking items into different categories based on their preferences.

📌 About the Project
The Tier List Maker helps users rank their favorite items, characters, games, movies, products, or anything they want using customizable ranking levels.

Users can organize items into different tiers and create their own personalized rankings.

✨ Features
Create custom tier lists.
Organize items into different ranking categories.
Drag and drop items between tiers (if implemented).
Customize tier names and colors (if implemented).
Simple and user-friendly interface.
Save or share tier lists (if implemented).
